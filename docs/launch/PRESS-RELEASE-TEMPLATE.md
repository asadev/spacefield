## Variants & customisation notes

### MENA outlets (Wamda, MENAbytes, Forbes Middle East)
- Emphasise the Dubai HQ and MENA serving angle
- Add a paragraph on broker-to-founder story (regional resonance)
- Use GST in time references

### Global tech press (TechCrunch, The Verge, Wired)
- Lead with the AI-agent angle, not the geography
- Switch GST → PT in time references
- Highlight the bootstrapped + solo-founder story

### Productivity press (Lifehacker, Zapier blog, The Verge tools)
- Add the "tool catalogue" angle — list the 20 tools by name
- Compare positioning to Notion + Zapier + Linear stack

### Hindi / Urdu / Arabic outlets
- Translation done by the maintainer personally for accuracy
- Keep founder quote in first person, translated naturally — don't
  use machine translation for the quote

## Embargo rules to communicate up-front

In the email body sending this:

```
Embargoed until [LAUNCH DATE] 09:00 GST / 06:00 BST / 01:00 EDT.

Sharing this 72h in advance so you have time to ask follow-up
questions, request assets, or book a 15-min founder Q&A before
launch.

Founder is available [TIMES] for Zoom / phone / WhatsApp voice.

Please confirm you'll honor the embargo, or let me know if your
publication has different rules.
```

## Don't-do list

- Don't send before T-7 — leak window too long.
- Don't promise exclusivity to anyone except in writing, and only
  if you genuinely mean it.
- Don't lift the embargo early because one outlet jumped — confront
  them privately, hold the line for the rest.
- Don't change the boilerplate paragraph between versions — it's
  what gets copy-pasted into stories.
